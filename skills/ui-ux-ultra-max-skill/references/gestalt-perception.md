# Gestalt and visual perception

These laws decide how people **group and read** a screen before they read a word. Use them to build structure with space and alignment instead of boxes and lines.

| Principle | What it says | Drives | Common failure |
|---|---|---|---|
| **Proximity** | Things close together belong together | Spacing *is* grouping: tight space inside a group, larger space between groups (e.g. 8 inside, 24–32 between). Labels sit closer to their field than to the previous field | Equal spacing everywhere, so nothing groups; a label floating between two inputs |
| **Similarity** | Things that look alike seem related | Same style means the same function. All tappable things share one treatment; all metadata shares one | Links styled like headings; two button styles for the same action |
| **Common region** | Things inside a shared boundary group together | Use a card or surface **only** when the region means something (a selectable item, a draggable unit) | Card-in-card nesting; boxing everything ("kit look") |
| **Uniform connectedness** | Visually connected things (lines, colour fills) group together strongest | Steppers, timelines, connected chips | Decorative connectors that imply false relationships |
| **Continuity** | The eye follows lines and curves | Alignment axes; horizontal scrollers that cut the last item to hint at more | Broken alignment that makes the eye jump |
| **Closure** | The mind completes incomplete shapes | Minimal icons; "peek" of the next card in a carousel | — |
| **Figure–ground** | We separate foreground from background | Modals, sheets and scrims; elevation for the active layer | Low-contrast overlays, ambiguous layers |
| **Common fate** | Things moving together group together | Animate grouped items together; staggered list entrance | Random motion |
| **Symmetry and order** | Symmetric layouts feel stable | Calm or trust screens: centred confirmations | Overusing centring for long text |
| **Focal point** | The element that differs captures attention first | Exactly one focal element per screen (pairs with Von Restorff) | Two heroes competing |

## Reading patterns

- **F-pattern**: text-heavy pages are scanned along the left edge and the top rows. Front-load headings and the first words of list items.
- **Z-pattern**: sparse marketing pages run top-left → top-right → diagonal → bottom-right CTA.
- **Layer-cake**: users scan headings only. Headings must carry meaning by themselves.
- **Spotted**: users hunt for specific things (numbers, links, bold text). Make the things they hunt for visually distinct.

## Visual weight (what attracts the eye first)

Size > colour contrast > saturation > position (top, left in LTR) > density/texture > shape oddity > motion (strongest, use rarely). Build the hierarchy by deciding the reading order **first**, then assigning weight in that order. Squint test: blur the screen; the focal element and the reading order must survive.
