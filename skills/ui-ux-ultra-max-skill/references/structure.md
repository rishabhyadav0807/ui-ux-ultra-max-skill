# Redesigns and navigation changes

Read this when the work redesigns shipped screens or changes navigation (new, merged, renamed or removed destinations).

## Inventory (redesigns in a repo, step 1)

List the shipped features the current screens reach (routes, stores, models: streaks, ranks, badges, unlocks, shares) and mark each one kept, moved or dropped with a reason. Anything unmarked tends to vanish.

## Structure (step 5)

Write each destination, what it holds, and which screens are pushed from it.

- **Peers.** When the brief calls features equal, peers or "together", they share one destination as equal blocks with no primary button between them, and a written order rule based on state (e.g. the block with an open next step comes first; a finished block moves down; reorder only when the destination opens, never while the user is looking). If you believe a different structure is better, propose it as a flagged assumption, never as a silent reinterpretation.
- **Names.** Any destination that is new, renamed or holds different content gets a name check: list everything it now holds, confirm the name covers all of it, give 2 alternatives, and suggest a 5-person test ("where would you find X?" for each item).

## Screens and states (step 8)

- A destination that shows progress also gets: first visit, in progress, just finished, done for today, and "used the other peer last" (this changes only the order; each feature's content stays its own).
- **Features stay independent:** one feature's content, rewards or streaks never depend on another's unless the brief says so, and links between them are entry points only. Any coupling you think helps is a flagged proposal.
- **Status** (rank, streak, badges) sits in one compact strip beside the feature that earns it, never as a destination's hero.
- A result that never changes (a quiz outcome, a personality or chart result) gets a return-visit state with something that refreshes, or is explicitly demoted with a reason.
- Every pushed flow of each destination is built, with its states.
