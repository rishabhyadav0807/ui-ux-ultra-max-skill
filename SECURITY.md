# Security

This skill is Markdown instructions plus metadata. It ships no executable code, but it does tell Claude to run tools (render screens, start reviewer agents, read your repo).

Report a problem privately through **Security → Report a vulnerability** on this repository. Please don't open a public issue. Examples worth reporting:

- Instructions that could make Claude run or download something you didn't ask for.
- Text that could be used to inject instructions into Claude through a design input (a screenshot, brief or file).
- Guidance that would make Claude enter credentials or personal data.

Expect a first reply within 7 days. Fixes ship as a patch release and are noted in `CHANGELOG.md`.
